# 抖音素材雷达飞书协作方案

本文档说明低粉爆款搜索、监控账号和飞书多维表格如何配合，让团队在飞书里完成素材判断、负责人分配、选题转化和复盘沉淀。

## 当前 MVP 边界

- Mac mini 负责采集、评分、下载、转写和报告归档。
- 飞书 Base 负责团队协作：去重、负责人、处理状态、选题价值、是否采纳、成稿链接、发布链接和复盘结论。
- Content OS 暂时只作为后续内容机会桥接；当前不要为了素材协作默认引入 Supabase。
- 系统不会覆盖飞书里人工填写的协作字段。重复同步时只更新素材基础字段。

## 推荐流程

1. 在 `douyin.aizao.ai/lowfan` 按关键词跑低粉爆款。
2. 在 `douyin.aizao.ai/accounts` 维护对标账号池并跑账号监控。
3. 每次运行结束后，系统自动按 `去重键` 同步到飞书 Base。
4. 运营同事在飞书 Base 里认领素材，填写 `处理状态`、`负责人`、`选题价值`、`是否已采纳`。
5. 被采纳的素材再进入公众号选题、短视频脚本或复盘流程。

## 建议视图

- `待判断素材`：筛选 `处理状态 = 待处理`。
- `已入选选题`：筛选 `是否已采纳 = 是` 或 `处理状态 = 已入选`。
- `账号监控`：筛选 `运行类型 = 对标账号监控`。
- `低粉爆款`：筛选 `运行类型 = 低粉爆款搜索`。
- `待补素材`：筛选 `素材缺口 非空` 或 `口播正文 为空`。
- `已发布复盘`：筛选 `发布链接 非空`。

## 环境变量

飞书结果库使用本机 `.env.local` 或生产环境变量，不要提交真实密钥：

```bash
FEISHU_BASE_SYNC_MODE=auto
FEISHU_BASE_APP_ID=
FEISHU_BASE_APP_SECRET=
FEISHU_BASE_APP_TOKEN=
FEISHU_BASE_TABLE_ID=
DY_HOT_PUBLIC_URL=https://douyin.aizao.ai
```

`DY_HOT_PUBLIC_URL` 用来生成可点击的 Markdown 报告、CSV 报告、无水印视频和口播文稿链接。

## 网页配置入口

管理员可以在 `douyin.aizao.ai/settings` 的“飞书结果库”面板里配置同步方式、Base Token、Table ID、飞书应用 App ID 和 App Secret。保存后配置会写入 Mac mini 本机 `douyin-monitor-ui/.env.local`。

- 留空的密钥字段不会覆盖已有配置，方便只调整同步方式或补单个字段。
- 页面配置状态和输入框只展示是否已配置和掩码，不在状态文案里展示完整 App Secret、Base Token 或 Table ID；“打开飞书结果库”链接会使用 Base URL。
- `auto` 模式优先使用 OpenAPI；如果缺少 OpenAPI 凭证，才回落到本机 `lark-cli`。正式协作建议配齐 OpenAPI，避免依赖个人登录状态。
